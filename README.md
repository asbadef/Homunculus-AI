# MedPilot-AI

- `Homunculus/` — the clinical knowledge vault (Obsidian); `docs/` — vision, specs, plans.
- `homunculus-engine/` — the rules engine, API, NCE file bridge.
- `dashboard/`, `homunculus-mobile/` — the clinician web panel and mobile companion.
- `homunculus-ml/` — the early-sepsis model.
- `medibus/` — Dräger **MEDIBUS** RS-232 bridge for ventilators (Evita/Savina/…); standalone,
  USB-stick deployable. Not for Kappa monitors — see `medibus/README.md`.
