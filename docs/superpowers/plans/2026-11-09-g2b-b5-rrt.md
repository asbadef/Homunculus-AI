**Goal:** Add «RRT çağır» on the live alarm system, and an `/rrt` screen with a rail badge. The screen shows the open calls and the unanswered urgent alarms on their way.

**Architecture:**
- **Engine.** The live in-memory `AckStore` gains `rrt_calls`, holding `{by, at, reason}` per `(patient_id, kind)`.
  - The new `POST /alerts/rrt-call` writes an `rrt_call` audit row first, then the store.
  - The board card's alerts carry `rrt_call`.
  - `/ack`, `prune` and discharge end a call.
  - `rehydrate` replays the `rrt_call` rows.
- **Dashboard.**
  - `rrt.js` derives the two lists from the board.
  - `RrtScreen` shows them.
  - The rail badge counts open calls.
  - The alarm screen gets a reason dialog.
- **Untouched.** The Postgres `escalation/` module. No snooze (owner D2).

    ```python
        async def call_rrt(authorization: str | None = Header(default=None), body: dict = Body(...)):
            """A person calls the rapid-response team to one active alarm (G2-B5, spec 2026-11-09, owner D1: the RRT
            comes only when called by hand).

            Keyed like `/ack` — patient and kind in the body, never in the path the access log writes. A device is
            refused (a device is exempt from permission checks, so the refusal is explicit): the call is a person's,
            named in the trail. An acknowledged alarm is refused (409): nobody is waiting for help on it. A second
            call answers the card and writes nothing: the first call stands. The trail before memory, as `/ack`
            (spec 2026-11-01, D3).
            """
            caller = await _caller(authorization)
            if caller.is_device:
                raise HTTPException(status_code=403, detail="RRT'yi bir kişi çağırır")
            _require(caller, ALERTS_ESCALATE)
            hospital = caller.hospital
            engine = _engine(hospital)
            store = _store(hospital)
            patient_id, kind = _body_patient_id(body), body.get("kind")
            if not isinstance(kind, str):
                raise HTTPException(status_code=400, detail="geçersiz kind")
            raw = body.get("reason")
            reason = raw.strip() if isinstance(raw, str) else ""
            if not RRT_REASON_MIN <= len(reason) <= RRT_REASON_MAX:
                raise HTTPException(status_code=400, detail="RRT çağrısının gerekçesi 3–500 karakter olmalı")
            who = _attribution(caller, body)
            await _require_patient(caller, authorization, patient_id)
            key = (patient_id, kind)
            if key not in live_keys(engine, store):
                raise HTTPException(status_code=404, detail="no such active alert")
            if key in store.acks:
                raise HTTPException(status_code=409, detail="alarm zaten yanıtlandı; RRT çağrısı açılmaz")
            if key not in store.rrt_calls:
                now = datetime.now(timezone.utc)
                audit.append(AuditEvent(hospital, "rrt_call", patient_id, kind,
                                        {**who, "reason": reason, "at": now.isoformat()}))
                store.call_rrt(patient_id, kind, who["actor"], reason, now)
            board = _card(hospital, patient_id)
            await broadcaster.publish(hospital, board)
            return board
    ```

    ```js
    // src/live/screens/rrt/rrt.js — the RRT screen's lists, from the board (G2-B5, spec D6, D7). Owner D1: the RRT
    // comes only when called by hand, so its own list is the open calls; the second list is what may yet need it —
    // the unanswered urgent alarms, which the engine escalates to the doctor, not to the RRT.
    import { waitingAlarms } from "../../data/boardStore.js";

    /** {known, stale, called, waiting}: `called` the alarms with an open call that nobody has acknowledged, the
     *  oldest call first; `waiting` the alarms that wait for an answer (`waitingAlarms`, its order) with urgency
     *  `immediate` and no call. `called`/`waiting` are null when the board cannot be read — never an empty list a
     *  reader would take for a quiet ward (Decision 18). */
    export function rrtQueue(board) {
      const { known, stale, items } = waitingAlarms(board);
      if (items === null) return { known, stale, called: null, waiting: null };
      const alerts = Array.isArray(board?.alerts) ? board.alerts : [];
      const called = alerts.filter((a) => a.rrtCall && !a.ack)
        .sort((a, b) => (a.rrtCall.atMs ?? Infinity) - (b.rrtCall.atMs ?? Infinity));
      const waiting = items.filter((a) => !a.rrtCall && a.urgency === "immediate");
      return { known, stale, called, waiting };
    }
    ```
