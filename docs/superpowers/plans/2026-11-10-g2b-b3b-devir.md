> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A per-patient shift handover. The outgoing person writes a D-Ö-D-Ö note and signs. The system seals a summary taken from the live board. The receiver chosen by the outgoing person countersigns. An unacknowledged critical alarm on the live board blocks the outgoing signature.

**Architecture:**
- **Engine:** the existing `admission/` handover routes, with no migration.
  - The critical gate reads `BoardLink.open_critical`, not the Postgres escalation table.
  - Opening a handover checks scope and admission state.
  - The note is structured and stored as JSON text in `narrative_note`.
  - `auto_populated_summary` is filled at the outgoing signature by `BoardLink.handover_summary`.
  - Two new GET routes: my handovers, and colleagues.
  - Audit rows are written through `trail.record`.
- **Dashboard:**
  - API methods and a pure `devir.js`;
  - a `/devir` screen with a «Yeni devir» dialog, and its route;
  - the `devir` i18n namespace;

- [ ] **Step 3: Note storage.** In `router.py`:
  ```python
  def _note_text(note: HandoverNote) -> str:
      """D5: the D-Ö-D-Ö note as JSON text in `narrative_note` (no migration)."""
      return json.dumps({"v": 1, **note.model_dump()}, ensure_ascii=False)

  def _note_of(text: str | None) -> dict | None:
      """D5: the stored note back as its four parts; a legacy plain-text note is its `situation`."""
      if not text:
          return None
      try:
          data = json.loads(text)
      except ValueError:
          data = None
      if isinstance(data, dict) and data.get("v") == 1:
          return {k: data.get(k) for k in ("situation", "background", "assessment", "recommendation")}
      return {"situation": text, "background": None, "assessment": None, "recommendation": None}
  ```
  `sign_outgoing` passes `narrative_note=_note_text(payload.note) if payload.note else payload.narrative_note`.
