# Group 2 · B1b — Nakil (one-step transfer) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An authorised clinician moves a lying-in patient to another bed in one action. The patient keeps her protocol number, her card, her monitor link, her alerts and her care team; the old bed goes to cleaning. The move refuses what the review's C-1 and C-2 allowed.

**Architecture:**
- **Server (`homunculus-engine`).**
  - One route, `POST /admissions/{admission_id}/transfer`, replaces the two closed routes. Its body names the bed (never a unit), a reason from six, an optional note and the reserved-bed answer.
  - `service.transfer_patient` walks the existing state machines inside one transaction, so no pending state is ever committed. It moves the protocol (O8), closes and copies the care team, and writes the arriving row as the source whole.
  - After the commit, `BoardLink.move` tells the old place by a removal frame, then puts the card on the new bed under the same key.
  - A card that did not move is moved again, by the same request or at the old bed's release (`_last_card_off`). It is never taken off.
  - The audit row `admission.transfer` carries the places, the moved protocol, the reason and `note: true|false`, never the note.
  - **No migration.** B1c's `0018_care_team_transfer` holds `admissions.transfer_reason` and `admissions.transfer_note` (spec D8, §5.9).
- **Dashboard.**
  - Kabul's «Taburcu» tab becomes «Nakil / Taburcu».
  - Each ACTIVE row of «Yatan hastalar» gets «Nakil» (`TransferDialog.jsx`).
  - A card that did not move leaves a note with «Kartı yeniden taşı».

**Tech Stack:** FastAPI, SQLAlchemy 2 (async), Alembic, Postgres 16, pytest. React 18, Vitest, Testing Library.

**Spec:** `docs/superpowers/specs/2026-11-09-g2b-b1b-nakil-design.md` (branch `docs/g2b-b1b-b1c` @ `4f9e9490`), with the owner's decisions D1–D8 of 2026-11-09. Companion: `2026-11-09-g2b-b1c-bakim-ekibi-design.md` §5.1 step 8 (the shared `0018`) and §5.4 (the care team at a transfer). **Read the spec's §0, §3 and §5 before Task 1.**

**Base:** the head of `feat/g2b-b1c-bakim-ekibi`, once B1c is done. **B1c is built first.** The spec's line numbers are at `c3965ed5`; B1c has moved some of them. Every edit below finds its text, never a line number. Where B1c may have changed the text an edit finds, the step says what to do.

"""The transfer's reason and note on the admission (G2-B1b, spec D4, D8, §5.9), as the models map
them: six reasons, checked by `ck_admissions_transfer_reason` with the same values as migration
0018's CHECK; the reason a short text; the note encrypted at rest and wide enough for the
ciphertext of 200 four-byte letters; both NULL unless a transfer writes them. No database."""
from __future__ import annotations

import re

from sqlalchemy import CheckConstraint

from homunculus.admission.models import PHI_COLUMN_LENGTH, Admission, TransferReason
from homunculus.crypto import EncryptedString, encrypt_phi

CHECK = "ck_admissions_transfer_reason"


def test_the_six_reasons_in_the_prototypes_order():
    assert [r.value for r in TransferReason] == [
        "CLINICAL_NEED", "TO_ICU", "ICU_TO_WARD", "ISOLATION", "PATIENT_OR_FAMILY_REQUEST",
        "OTHER"]


def test_the_check_names_exactly_the_six_reasons():
    checks = [c for c in Admission.__table__.constraints
              if isinstance(c, CheckConstraint) and c.name == CHECK]
    assert len(checks) == 1

    moved.

    1. The source walks ACTIVE → PENDING_TRANSFER → TRANSFERRED and its bed OCCUPIED →
       PENDING_TRANSFER_OUT → HOUSEKEEPING (T3): no machine changes, and no pending state is
       ever committed.
    2. The source gives up its protocol (O8) and its care team is closed (T7). A flush takes it
       out of `uq_admissions_tenant_protocol` and `uq_admissions_open_identity` before the insert.
    3. The arriving row is the source whole (`_OWN_TO_EACH_ROW` aside): `identity_digest` and B1a's
       form fields included (T6, F4). It is ACTIVE on the target bed, in its real unit, now, with
       the moved protocol and the move's own reason and note (D8).
    4. The target goes OCCUPIED, from AVAILABLE, or from RESERVED when the route confirmed it
       (`reserved_ok`, B3a R5). The transition clears the reservation's note (F10).
    5. The closed rows are copied, active, onto the arriving row: same role, window and grantor."""
    if admission.state != AdmissionState.ACTIVE:
        raise WorkflowError(
            f"Only an ACTIVE admission is transferred (current: {admission.state.value}).")
    if target_bed.state != BedState.AVAILABLE and not (
            reserved_ok and target_bed.state == BedState.RESERVED):
        raise WorkflowError(
            f"Target bed is not AVAILABLE (state: {target_bed.state.value}).",
            errors.BED_NOT_AVAILABLE)
    source_bed = await db.get(Bed, admission.bed_id)
    now = _now()

    admission.transition_to(AdmissionState.PENDING_TRANSFER)
    admission.transition_to(AdmissionState.TRANSFERRED)
    source_bed.transition_to(BedState.PENDING_TRANSFER_OUT)
    source_bed.transition_to(BedState.HOUSEKEEPING)

    moved_protocol, admission.protocol_no = admission.protocol_no, None
    team = list((await db.execute(select(CareTeamMember).where(
        CareTeamMember.admission_id == admission.id,
        CareTeamMember.is_active.is_(True)))).scalars().all())
    for member in team:
        member.is_active = False
        member.closed_at = now
    await db.flush()

    carried = {attr.key: getattr(admission, attr.key)
               for attr in Admission.__mapper__.column_attrs
               if attr.key not in _OWN_TO_EACH_ROW}
    arriving = Admission(
        **carried, state=AdmissionState.ACTIVE, bed_id=target_bed.id,
        admitting_unit_id=target_unit_id, admission_datetime=now, protocol_no=moved_protocol,
        source_admission_id=admission.id, transfer_confirm_deadline=None,
        transfer_reason=reason, transfer_note=note)
    db.add(arriving)
    target_bed.transition_to(BedState.OCCUPIED)
    await db.flush()                               # the arriving row's id, for the team below

    for member in team:
        db.add(CareTeamMember(
            admission_id=arriving.id, user_id=member.user_id, role=member.role,
            granted_by_id=member.granted_by_id, window_start=member.window_start,
            window_end=member.window_end))
    await db.flush()
    return arriving, len(team)

            await self._send(tenant, record.patient_id, stored)

                             .where(Bed.id == bed_id))).scalar_one()


async def card_of(db: AsyncSession, admission_id: uuid.UUID) -> dict:
    """The card of an admission's place, as plain values: `key` (`board_key`: its protocol, a
    legacy admission's H-number), `patient_number`, the name, birth date and sex, the bed's id and
    label, and its real unit."""

        .join(Bed, Bed.id == Admission.bed_id)

        .where(Admission.id == admission_id))).one()

        .order_by(Admission.created_at.desc()).limit(1))).scalar_one_or_none()


async def where_now(db: AsyncSession,

    forward to the first row that is not TRANSFERRED — open, or DISCHARGED since. None when the
    chain breaks off (a transfer the closed routes left half done)."""

// src/live/screens/kabul/TransferDialog.jsx — «Nakil» (Group 2 · B1b, spec §4): the patient moves to
// another bed in one step. The dialog says where she lies now and that the old bed goes to cleaning.
// It asks:
// - the reason, one of six (D4);
// - a note of at most 200 characters, with its count — optional, but «Diğer» needs one (D8), as
//   B3a's out-of-service dialog does;
// - the new bed, from the picker opened on her unit. Her own bed is occupied, so it is not offered.
// A reserved bed is asked about first (ReservedAsk.jsx, B3a's question, its note read from
// GET /tenant/occupancy) and goes out with `confirm_reserved`. A bed reserved after the picker read
// it comes back `bed_reserved`: the beds are read again and the question is asked.
//
// A critical alarm nobody acknowledged is said in the warning tone and holds nothing (D7): a
// patient often moves because she is worse, and her alarms move with her. The tab passes it only
// once the board has loaded — a hint, not a hold. The server checks all of it again; a refusal is
// said on the toast in words, `field_invalid:note` in the transfer's own (X7).
//
// The dialog stays open and held until the tab has read its list again (A-17). What the answer says
// beyond the move — the card did not reach the new bed (`board: failed`) — is the tab's to keep
// (DischargeTab.jsx, «Kartı yeniden taşı»).
import React, { useState } from "react";
import { useI18n } from "../../i18n/I18nProvider.jsx";
import { useSession } from "../../session/SessionProvider.jsx";
import { useStructure } from "../../data/StructureProvider.jsx";
import { normId } from "../../data/structure.js";
import { Button, Field, Modal, Note, Select, useToast } from "../../ui/index.js";
import { reasonOf, refusedFor } from "../admin/refusal.js";
import { BedPicker } from "./BedPicker.jsx";
import { ReservedAsk } from "./ReservedAsk.jsx";

/** The six reasons (admission/models.py TransferReason), in the prototype's order. */
export const TRANSFER_REASONS = Object.freeze(["CLINICAL_NEED", "TO_ICU", "ICU_TO_WARD", "ISOLATION", "PATIENT_OR_FAMILY_REQUEST", "OTHER"]);
/** A note's bound in characters (admission/schemas.py TRANSFER_NOTE_MAX). */
export const NOTE_MAX = 200;

/** The body POST …/transfer takes (admission/schemas.py TransferRequest): the bed, the reason, the
 *  note trimmed (null when blank), and `confirm_reserved` only after a yes to a reserved bed. */
export function transferBody({ bedId, reason, note, confirmReserved = false }) {
  const text = String(note ?? "").trim();
  return { target_bed_id: bedId, reason, note: text || null, ...(confirmReserved ? { confirm_reserved: true } : null) };
}

/** `row`: the admitted patient's row (AdmissionRow); `subject`: her bed, "label · room · unit";
 *  `critical`: the loaded board shows her a critical alarm nobody acknowledged. `onDone({answer,
 *  body, to})` is awaited — the tab reads its list again before the dialog lets go (A-17);
 *  `onRefused` is not. */
export function TransferDialog({ row, subject, critical = false, onClose, onDone, onRefused }) {
  const { t } = useI18n();
  const { store } = useSession();
  const { structure, index, phase, error, reload } = useStructure();
  const toast = useToast();
  const [reason, setReason] = useState("");
  const [note, setNote] = useState("");
  const [unitId, setUnitId] = useState(null);           // a unit chosen in the picker
  const [target, setTarget] = useState(null);           // {id, unitId, label}
  const [ask, setAsk] = useState(null);                 // the reserved-bed question: {bedId, bed}
  const [tried, setTried] = useState(false);
  const [busy, setBusy] = useState(false);
  // The picker opens on her unit: her bed's, from the structure (A-12), until another is chosen.
  const shownUnit = unitId ?? index.beds.get(normId(row.bed_id))?.unitId ?? null;
  const errors = {
    reason: reason ? null : t("kabul.transfer.reasonNeeded"),
    note: reason === "OTHER" && !note.trim() ? t("kabul.transfer.noteNeeded") : null,
    bed: target ? null : t("kabul.transfer.bedNeeded"),
  };
  const wrong = Object.values(errors).some(Boolean);

  async function submit(event, confirmed = false) {
    event?.preventDefault();
    if (busy) return;
    if (wrong) {
      setTried(true);
      return;
    }
    if (index.beds.get(normId(target.id))?.state === "RESERVED" && !confirmed) {
      setAsk({ bedId: target.id, bed: target.label });
      return;
    }
    const body = transferBody({ bedId: target.id, reason, note, confirmReserved: confirmed });
    setBusy(true);
    try {
      const answer = await store.track(() => store.api.transfer(row.id, body));
      const failed = answer?.board === "failed";
      toast(t(failed ? "kabul.transfer.doneBoardFailed" : "kabul.transfer.done", { from: subject, to: target.label }),
        failed ? "warn" : "ok");
      await onDone({ answer, body, to: target.label });
    } catch (err) {
      if (err?.apiCode === "bed_reserved") {
        // Reserved after the picker read it; nothing was written. Read the beds again and ask.
        await reload();
        setAsk({ bedId: target.id, bed: target.label });
        return;
      }
      const said = err?.apiCode === "field_invalid:note" ? t("kabul.transfer.noteInvalid") : reasonOf(t, err);
      toast(refusedFor(t, subject, said), "error");
      onRefused?.();
    } finally {
      setBusy(false);
    }
  }

  return (
    <>
      <Modal open title={t("kabul.transfer.title", { bed: subject })} onClose={onClose} busy={busy}
        actions={(
          <>
            <Button onClick={onClose} busy={busy}>{t("common.cancel")}</Button>
            <Button type="submit" form="transfer-form" variant="primary" icon="swap" busy={busy}>{t("kabul.transfer.submit")}</Button>
          </>
        )}>
        <form id="transfer-form" noValidate onSubmit={submit} className="grid gap-2">
          <p className="m-0 text-14">{t("kabul.transfer.now", { bed: subject })}</p>
          {critical ? <Note icon="alert">{t("kabul.transfer.critical")}</Note> : null}
          <Field label={t("kabul.transfer.reason")} required error={tried ? errors.reason ?? undefined : undefined}>
            <Select value={reason} disabled={busy} onChange={(e) => setReason(e.target.value)}>
              <option value="">{t("kabul.transfer.choose")}</option>
              {TRANSFER_REASONS.map((value) => <option key={value} value={value}>{t(`kabul.transfer.reasons.${value}`)}</option>)}
            </Select>
          </Field>
          <Field label={t("kabul.transfer.note")} required={reason === "OTHER"} hint={t("kabul.transfer.noteHint")}
            error={tried ? errors.note ?? undefined : undefined}>
            <textarea value={note} maxLength={NOTE_MAX} rows={3} readOnly={busy} onChange={(e) => setNote(e.target.value)}
              className="w-full rounded-ctl border border-line2 bg-card2 px-[11px] py-[9px] font-text text-14.5 text-ink outline-none focus:border-pri" />
          </Field>
          <p aria-hidden="true" className="m-0 -mt-2 text-right text-12 text-mute">{note.length} / {NOTE_MAX}</p>
          <fieldset className="m-0 min-w-0 border-0 p-0">
            <legend className="mb-1.5 text-13.5 font-semibold text-mute">{t("kabul.transfer.bed")}</legend>
            <BedPicker structure={structure} phase={phase} error={error} onRetry={reload}
              unitId={shownUnit} bedId={target?.id ?? null}
              onUnit={(id) => { setUnitId(id); setTarget(null); }}
              onBed={(bed) => setTarget(bed)}
              invalid={tried && Boolean(errors.bed)} focusId="transfer-bed"
              describedBy={tried && errors.bed ? "transfer-bed-error" : undefined} />
            {tried && errors.bed
              ? <p id="transfer-bed-error" role="alert" className="m-0 mt-1 text-12.5 font-semibold text-crit-ink">{errors.bed}</p>
              : null}
          </fieldset>
        </form>
      </Modal>
      {ask ? (
        <ReservedAsk bedId={ask.bedId} bed={ask.bed} confirmKey="kabul.transfer.reservedConfirm"
          onCancel={() => setAsk(null)}
          onConfirm={() => { setAsk(null); submit(null, true); }} />
      ) : null}
    </>
  );
}
