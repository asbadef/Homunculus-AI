# G3-04 «Eczane» (Pharmacy page) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A read-only ward page `/eczane` for `pharmacy.view` — every patient in the caller's scope in one table (vasopressors, the antibiotic state, creatinine, today's fluid balance), the antibiotic clocks that are running or passed first — built by one server read, `GET /pharmacy`, from what the system already holds.

**Architecture:** Spec `docs/superpowers/specs/2026-11-11-g3-eczane-design.md` (b660ceeb); read it whole before your first task. Engine: one new permission key with its migration `0019` (permission rows only), `creatinine_at` on the board card's `meds` block, one tenant-wide fluid read in `api/fluids.py`, a new pure module `homunculus/api/pharmacy.py` (the antibiotic state in `_meds`' fields, the row, the order, the counters, the fluid totals) and one route beside `/patients` that reads through `_board_for`. Dashboard: `screens/eczane/` (a pure model, a 30-second hook, the screen), the `eczane` i18n namespace, one route between `devir` and `ozet`; the browser sums, sorts and judges nothing.

**Tech Stack:** Python 3.12 / FastAPI / pytest; React 18 / vitest / Testing Library.

### The shared contract (the names every task uses)

- **Key:** `pharmacy.view`, appended after `summary.view` in four places, in the same order: `auth/permissions.py` `PERMISSIONS`, `catalogue.js` `PERMISSION_KEYS`, `admin.testutil.js` `PERMISSION_TEXTS`, `perms.js` (four languages). - **Engine functions** (`homunculus/api/pharmacy.py`): `antibiotic_of(meds) -> dict`, `pressors_of(meds) -> list[dict]`, `fluid_of(entries, day) -> dict | None`, `row_of(card, fluid) -> dict`, `sort_key(row)`, `counts_of(rows) -> dict`, `ward_pharmacy(cards, audit, *, hospital, now, zone, start_a, start_b) -> dict`; (`homunculus/api/fluids.py`) `read_entries_by_patient(audit, hospital, *, since, until) -> tuple[dict[str, list[FluidEntry]], bool]`, `WARD_READ_LIMIT = 20000`.
- **`GET /pharmacy`** answers, in this key order: `now`, `antibiotic_window_min` (60), `antibiotic_window_source` (`"surviving-sepsis-campaign-2026"`), `fluid_day` `{start, end}`, `fluid_truncated`, `counts` `{patients, clock_running, clock_missed, on_pressor, recognized, recognized_no_record}`, `rows`, `scope`, `scope_note`. - **Dashboard:** `api.pharmacy()`; `usePharmacy(store, {everyMs})` → `{data, error, refresh}`, `PHARMACY_TICK_MS = 30_000`; `pharmacyModel.js`: `PHARMACY_FRESH_MS = 90_000`, `isFresh(answer, error, nowMs)`, `durationParts(seconds)`, `antibioticCell(row, nowMs, fresh)`, `pressorLines(row, nowMs, fresh)`, `fluidCell(row)`, plus `creatinineCell(row)` and `msOf(iso)`; `EczaneScreen`; route `{ id: "eczane", path: "/eczane", icon: "pill", labelKey: "eczane.nav", shortKey: "eczane.navShort", perms: ["pharmacy.view"], work: true, nav: "main" }`.

```python
def _entries_by_patient(rows, *, since: datetime, until: datetime) -> dict[str, list[FluidEntry]]:
    """The row → entry step `read_entries` and `read_entries_by_patient` share: each patient's fluid entries
    measured in [since, until], oldest first, each with its withdrawal. A `chart_retract` withdraws an entry of the
    SAME patient only (as `api/tasks.py` `_stamps_by_patient`): a row naming another patient's entry id touches
    nothing. A row the trail cannot read — not a finite number, a time with no zone — is left out, never a 0."""
    withdrawn: dict[tuple[str, int], dict] = {}
    for rec in rows:
        entry = rec.payload.get("entry")
        if rec.event_type == RETRACT and isinstance(entry, int) and not isinstance(entry, bool):
            withdrawn[(rec.patient_id, entry)] = {"reason": str(rec.payload.get("reason") or ""),
                                                  "by": str(rec.payload.get("retracted_by") or ""),
                                                  "at": _iso(_instant(rec.ts))}
    found: dict[str, list[FluidEntry]] = {}
    for rec in rows:
        if rec.event_type != "chart" or rec.subject not in INTAKE + OUTPUT:
            continue
        at, value = _instant(rec.payload.get("obs_ts")), rec.payload.get("value")
        if at is None or not _finite_number(value) or not since <= at <= until:
            continue
        found.setdefault(rec.patient_id, []).append(
            FluidEntry(rec.id, rec.subject, float(value), at, str(rec.payload.get("charted_by") or ""),
                       withdrawn.get((rec.patient_id, rec.id))))
    return {pid: sorted(entries, key=lambda e: (e.at, e.entry)) for pid, entries in found.items()}


def read_entries_by_patient(audit: AuditLog, hospital: str, *, since: datetime,
                            until: datetime) -> tuple[dict[str, list[FluidEntry]], bool]:
    """`read_entries` for every patient of the tenant in ONE read (G3-04, spec D13): what the Eczane page's poll
    needs — one read per request, not one per patient. A patient with no entry in the window has no key. It asks
    for one row more than WARD_READ_LIMIT: only that extra row proves a cut, so exactly the limit is whole."""
    fetched = audit.records(tenant=hospital, event_types={"chart", RETRACT}, since=since - BEDSIDE_SKEW,
                            limit=WARD_READ_LIMIT + 1, newest=True)
    truncated = len(fetched) > WARD_READ_LIMIT
    rows = fetched[max(len(fetched) - WARD_READ_LIMIT, 0):]      # drop the extra, OLDEST row
    return _entries_by_patient(rows, since=since, until=until), truncated
```

```python
# homunculus-engine/src/homunculus/api/pharmacy.py
"""Eczane (G3-04): the pharmacist's ward page, built by the server from what the system already holds (spec D1, D4).

Pure builders, no route. A row is one scoped board card: its `identity` (bed, name) and its `meds` block
(`api/board.py` `_meds`: the vasopressor rates and when each was charted, the three-valued antibiotic record, the
antibiotic clock, creatinine and its time), with the current fluid day's intake − output from the fluid ledger
(`api/fluids.py`). The antibiotic state, the row order, the counters and the fluid totals are decided here: the
browser sums, sorts and judges nothing (G2-A3 Decision 1).

The one sourced number is the engine's own 1-hour antibiotic window (`rules/antibiotic_clock.py` WINDOW;
surviving-sepsis-campaign-2026 — a strong recommendation on very low certainty evidence), and the clock itself is
`_meds`': this module adds no window, no threshold and no judgement. Creatinine and the fluid balance are a number
and its time; the vault holds no renal-dosing threshold and no fluid-balance target. «Kayıt yok» is never
«verilmedi»: `antibiotic_given` travels three-valued, and a recognised patient with no counted administration is
worded by the clock (spec D8). Homunculus does not diagnose, order or advise a dose.

It reads the cards' `identity` and `meds` only and holds no reference to the engine."""
from __future__ import annotations

import re
from datetime import datetime, timezone

from homunculus.api.audit import AuditLog
from homunculus.api.clinical import BEDSIDE_SKEW
from homunculus.api.fluids import FluidEntry, fluid_day, read_entries_by_patient, totals
from homunculus.rules.antibiotic_clock import WINDOW as ANTIBIOTIC_WINDOW

#: The vault's source note for the window, as `rules/antibiotic_clock.py` cites it. The page names it with both
#: halves — strong recommendation, very low certainty of evidence (spec D9).
ANTIBIOTIC_WINDOW_SOURCE = "surviving-sepsis-campaign-2026"
#: The two states whose clock is still unanswered: they lead the page and carry `remaining_sec` (spec D10, §3.1).
CLOCK_OPEN = ("running", "missed")
_DIGITS = re.compile(r"(\d+)")


def _iso(at: datetime | None) -> str | None:
    return None if at is None else at.astimezone(timezone.utc).isoformat()


def _number(value) -> bool:
    return isinstance(value, (int, float)) and not isinstance(value, bool)


def antibiotic_of(meds: dict | None) -> dict:
    """The antibiotic state of one card, in `_meds`' own fields (spec §3.1). With C the clock, A the counted
    administration's time and G the three-valued record: C and no A is `running` while `remaining_sec > 0` — the
    rule's own boundary (`antibiotic_clock.evaluate`) — and `missed` from 0 down; C and A is `met` or `late` by the
    engine's `met`; A without C is `given`; neither is `none`, whether G is null (nobody charted) or false (a 0, or a
    dose stamped before recognition). `given` carries G unchanged, so a reader can still tell the two. No state says
    «verilmedi». A card without `meds` (never measured) is `none`."""
    meds = meds or {}
    clock = meds.get("antibiotic_clock") or None
    given_at = meds.get("antibiotic_at")
    if clock is not None and given_at is None:
        state = "running" if clock["remaining_sec"] > 0 else "missed"
    elif clock is not None:
        state = "met" if clock.get("met") is True else "late"
    else:
        state = "given" if given_at is not None else "none"
    return {"state": state, "given": meds.get("antibiotic_given"), "given_at": given_at,
            "recognized_at": None if clock is None else clock.get("recognized_at"),
            "deadline": None if clock is None else clock.get("deadline"),
            "remaining_sec": clock["remaining_sec"] if state in CLOCK_OPEN else None}


def pressors_of(meds: dict | None) -> list[dict]:
    """Every drug with a charted rate, in the card's own order (`api/board.py` `_PRESSORS`'), with the rate and when
    it was charted (spec D6). A 0 is listed — the screen says «durduruldu» — and a drug never charted is absent."""
    meds = meds or {}
    charted_at = meds.get("pressors_at") or {}
    return [{"drug": drug, "rate": rate, "at": charted_at.get(drug)}
            for drug, rate in (meds.get("pressors") or {}).items() if _number(rate)]


def fluid_of(entries: list[FluidEntry], day: tuple[datetime, datetime]) -> dict | None:
    """The fluid day's intake, output and balance of one patient (`fluids.totals` over [start, end)), the number of
    entries and the newest one's measurement time. None when the patient has no entry in the day that was not
    withdrawn: an uncharted day is not a balance of 0 (spec D13)."""
    start, end = day
    live = [e for e in entries if e.retracted is None and start <= e.at < end]
    if not live:
        return None
    summed = totals(live, start, end)
    return {"in_ml": summed["in"], "out_ml": summed["out"], "balance_ml": summed["balance"],
            "entries": len(live), "last_at": _iso(max(e.at for e in live))}


def row_of(card: dict, fluid: dict | None) -> dict:
    """One row of the page from one board card (spec D5, §3). `measured` is false for an identity-only card (an
    admitted patient the engine never measured: no `meds` block), whose row is all «Kayıt yok». A card the bed table
    places on no unit has `unit_id` None, and one with no identity an empty label and name."""
    identity = card.get("identity") or {}
    meds = card.get("meds") or None
    creatinine = None if meds is None else meds.get("creatinine")
    return {
        "patient_id": card["patient_id"],
        "bed_label": identity.get("bed_label") or "",
        "bed_id": identity.get("bed_id") or None,
        "unit_id": identity.get("unit_id") or None,
        "display_name": identity.get("display_name") or "",
        "measured": meds is not None,
        "on_pressor": bool(meds and meds.get("on_pressor")),
        "pressors": pressors_of(meds),
        "antibiotic": antibiotic_of(meds),
        "creatinine": None if creatinine is None else {"value": creatinine, "at": meds.get("creatinine_at")},
        "fluid": fluid,
    }


def _natural(label: str) -> tuple:
    """A bed label as the board orders it (`screens/beds/order.js` `byBed`): digit runs compared as numbers, the rest
    case-folded — «YBU 1-2» before «YBU 1-10»."""
    return tuple((0, int(part), "") if part.isdecimal() else (1, 0, part.casefold())
                 for part in _DIGITS.split(label) if part)


def sort_key(row: dict) -> tuple:
    """The page's order (spec D10, §3.2): the open clocks first, least `remaining_sec` first — the longest passed,
    then the least time left; then the other rows on a vasopressor; then the rest. Inside a group the board's bed
    order: unit id, a row on no unit last, the bed label (else the patient key) naturally, the patient key."""
    group = 0 if row["antibiotic"]["state"] in CLOCK_OPEN else 1 if row["on_pressor"] else 2
    unit = row["unit_id"] or ""
    return (group, row["antibiotic"]["remaining_sec"] if group == 0 else 0, unit == "", unit,
            _natural(row["bed_label"] or row["patient_id"]), row["patient_id"])


def counts_of(rows: list[dict]) -> dict:
    """The four counters (spec D11). By the engine's rules a recognised patient with no counted administration is
    exactly a `running` or `missed` row, so `recognized_no_record` is their sum."""
    running = sum(1 for row in rows if row["antibiotic"]["state"] == "running")
    missed = sum(1 for row in rows if row["antibiotic"]["state"] == "missed")
    return {"patients": len(rows), "clock_running": running, "clock_missed": missed,
            "on_pressor": sum(1 for row in rows if row["on_pressor"]),
            "recognized": sum(1 for row in rows if row["antibiotic"]["recognized_at"] is not None),
            "recognized_no_record": running + missed}


def ward_pharmacy(cards: list[dict], audit: AuditLog, *, hospital: str, now: datetime, zone, start_a: int,
                  start_b: int) -> dict:
    """The answer of `GET /pharmacy` without its scope block (spec §3). `cards` are the caller's scoped board cards;
    the fluid day is the one that holds `now` (`fluids.fluid_day`), read once for the whole tenant up to
    now + BEDSIDE_SKEW and summed per card over [day start, day end) — a row's balance equals «today» in that
    patient's Sıvı box. Only the cards handed in become rows: another patient's entries are read and dropped."""
    day = fluid_day(now, zone, start_a, start_b)["day"]
    by_patient, truncated = read_entries_by_patient(audit, hospital, since=day[0], until=now + BEDSIDE_SKEW)
    rows = sorted((row_of(card, fluid_of(by_patient.get(card["patient_id"], []), day)) for card in cards),
                  key=sort_key)
    return {"now": _iso(now),
            "antibiotic_window_min": int(ANTIBIOTIC_WINDOW.total_seconds() // 60),
            "antibiotic_window_source": ANTIBIOTIC_WINDOW_SOURCE,
            "fluid_day": {"start": _iso(day[0]), "end": _iso(day[1])},
            "fluid_truncated": truncated,
            "counts": counts_of(rows),
            "rows": rows}
```

```js
// src/live/screens/eczane/pharmacyModel.js — «Eczane» (G3-04): what the page's cells say, from one row of the server's
// answer. Pure: no React, no translator, no clock of its own.
//
// THE SERVER DECIDES (spec D4; G2-A3 Decision 1). Each row's `antibiotic.state`, the order of the rows, the four
// counters and the fluid totals are the engine's (`api/pharmacy.py`). Nothing here recomputes, re-sorts or judges
// them: this module picks the text KEY for the state the server sent and hands back the instants and numbers the
// screen formats. The two things the screen does compute are the two the server cannot send — an age, and the time
// left to or passed since `deadline` — from the server's ISO stamps against the board's skew-corrected clock, and
// only while the answer is fresh (spec D17, §5.1).
//
// A LIST THAT IS NOT FRESH NEVER READS AS TODAY'S (spec D18, §6). `isFresh` is the one rule; with `fresh` false the
// `running` and `missed` cells stop counting and read in the past tense with the one stamp that stays true (the
// deadline), and a vasopressor's age becomes its charted time.
//
// TONES MIRROR THE ENGINE'S SEVERITIES AND NOTHING ELSE (spec D14): `missed` is `crit` and `running` is `high`, the
// severities `rules/antibiotic_clock.py` gives `antibiotic_overdue` and `antibiotic_due`. Every other state,
// creatinine and the fluid balance carry no tone at all. Nothing is green.
import { PRESSORS } from "../patient/meds/medsFields.js";

/** §6: three polls. An answer whose `now` is further behind the screen's clock than this is not fresh. */
export const PHARMACY_FRESH_MS = 90_000;
/** The whole text keys of the two sentences the Meds box prints a vasopressor with (D6, D20). */
const RUNNING = "patient.medsRunning";
const STOPPED = "patient.medsStopped";
const TONES = Object.freeze({ missed: "crit", running: "high" });
const DRUG_KEYS = new Map(PRESSORS.map((p) => [p.key, p.labelKey]));

/** An ISO stamp as epoch milliseconds, or null for one that is missing or does not parse. */
export function msOf(iso) {
  const ms = typeof iso === "string" ? Date.parse(iso) : Number.NaN;
  return Number.isFinite(ms) ? ms : null;
}

/** §6: fresh = the last read succeeded and the answer's `now` is at most PHARMACY_FRESH_MS behind the screen's
 *  clock (a hidden tab shown again is not fresh until its poll lands). No answer, or a clock that is no number, is
 *  not fresh. */
export function isFresh(answer, error, nowMs) {
  if (!answer || error) return false;
  const at = msOf(answer.now);
  return at !== null && typeof nowMs === "number" && Number.isFinite(nowMs) && nowMs - at <= PHARMACY_FRESH_MS;
}

/** §5.1: a duration as its text key and parameters. `n = floor(seconds / 60)`, as the engine's alarm text counts
 *  (`int(seconds // 60)`): 0 is «<1 dk», under 120 «{n} dk», from 120 on «{h} sa {m} dk». A negative duration is 0;
 *  one that is no number has no text (null). */
export function durationParts(seconds) {
  if (typeof seconds !== "number" || !Number.isFinite(seconds)) return null;
  const n = Math.floor(Math.max(0, seconds) / 60);
  if (n === 0) return { key: "eczane.dur.under", params: {} };
  if (n < 120) return { key: "eczane.dur.min", params: { n } };
  return { key: "eczane.dur.hm", params: { h: Math.floor(n / 60), m: n % 60 } };
}

/** The antibiotic cell of one row (spec §3.1, D7, D8, D14, §6): `{ state, key, tone, duration, timeMs, second }`.
 *  - `state` is the server's word, untouched; `key` the text for it; `tone` "crit" | "high" | null.
 *  - `duration` ({key, params} | null) fills `{duration}`: the time to the deadline (`running`) or since it
 *    (`missed`), from the server's `deadline` against `nowMs` — the server's own `remaining_sec` when that cannot
 *    be computed. The STATE WORD never follows the screen's clock: a `running` row whose deadline passes between
 *    two polls reads «<1 dk kaldı» until the next answer says `missed`.
 *  - `timeMs` (number | null) fills `{time}`: the administration's charted time (`met`, `late`, `given`), or the
 *    deadline in the two past-tense twins of a list that is not fresh.
 *  - `second` ({key, timeMs} | null): «tanınma {saat} · uygulama kaydı yok», under `running` and `missed`.
 *  A state this build does not know is printed as the server's own word (`eczane.ab.unknown`), never as «Kayıt yok». */
export function antibioticCell(row, nowMs, fresh) {
  const ab = row?.antibiotic ?? {};
  const state = ab.state ?? null;
  const plain = (key, timeMs = null) => ({ state, key, tone: null, duration: null, timeMs, second: null });
  if (state === "running" || state === "missed") {
    const deadline = msOf(ab.deadline);
    const second = { key: "eczane.ab.noAdmin", timeMs: msOf(ab.recognized_at) };
    if (!fresh) {
      return { state, key: state === "running" ? "eczane.ab.staleRunning" : "eczane.ab.staleMissed",
        tone: TONES[state], duration: null, timeMs: deadline, second };
    }
    const sign = state === "running" ? 1 : -1;
    const seconds = deadline !== null && typeof nowMs === "number" && Number.isFinite(nowMs)
      ? (sign * (deadline - nowMs)) / 1000
      : (typeof ab.remaining_sec === "number" ? sign * ab.remaining_sec : Number.NaN);
    return { state, key: `eczane.ab.${state}`, tone: TONES[state], duration: durationParts(seconds), timeMs: null, second };
  }
  if (state === "met" || state === "late" || state === "given") return plain(`eczane.ab.${state}`, msOf(ab.given_at));
  if (state === "none") return plain("eczane.noRecord");
  return plain("eczane.ab.unknown");
}

/** The vasopressor lines of one row (spec D6), in the server's order: `{ drug, drugKey, key, rate, at, atMs, aged }`.
 *  `key` is the Meds box's own sentence — running for a rate above 0, stopped for a 0. `drugKey` is the drug's name
 *  in the dictionary, or null for a drug this build does not know (the screen then prints the server's word).
 *  `aged`: print the charted time as an age (`ageText(t, at, nowMs)`) — only while the answer is fresh and the
 *  stamp reads; otherwise the charted time itself (`dayStamp(atMs)`), or a dash for a rate that came without one. */
export function pressorLines(row, nowMs, fresh) {
  const list = Array.isArray(row?.pressors) ? row.pressors : [];
  return list.filter((p) => typeof p?.rate === "number" && Number.isFinite(p.rate)).map((p) => {
    const atMs = msOf(p.at);
    return {
      drug: String(p.drug ?? ""), drugKey: DRUG_KEYS.get(p.drug) ?? null, key: p.rate > 0 ? RUNNING : STOPPED,
      rate: p.rate, at: p.at ?? null, atMs,
      aged: Boolean(fresh) && atMs !== null && typeof nowMs === "number" && Number.isFinite(nowMs),
    };
  });
}

/** Creatinine as the row carries it (spec D12): `{ value, atMs }`, or null when none was ever observed. A number
 *  and its time — no tone, no threshold, no trend. */
export function creatinineCell(row) {
  const c = row?.creatinine;
  if (!c || typeof c.value !== "number" || !Number.isFinite(c.value)) return null;
  return { value: c.value, atMs: msOf(c.at) };
}

/** Today's fluid balance as the row carries it (spec D13): `{ balance, intake, output, entries, lastMs }`, or null
 *  for a patient with no entry in the fluid day — «Bugün kayıt yok», never «0 mL». The numbers are the server's
 *  sums; no tone, no target. */
export function fluidCell(row) {
  const f = row?.fluid;
  if (!f || typeof f !== "object") return null;
  return { balance: f.balance_ml, intake: f.in_ml, output: f.out_ml, entries: f.entries, lastMs: msOf(f.last_at) };
}
```

```js
// src/live/screens/eczane/usePharmacy.js — reads GET /pharmacy on mount and every 30 s (G3-04, spec D17), in the
// shape of gorevler/useTasks.js. A failed read keeps the last answer and reports the error: the screen then says
// the list is not fresh, and never calls it empty (spec D18, §6). An answer without a `rows` array is a failed
// read (`error.malformed`), never an empty ward. The tab shown again reads at once: a list read before the tab was
// hidden is not fresh, and the pharmacist should not wait a whole tick for today's.
import { useCallback, useEffect, useRef, useState } from "react";

export const PHARMACY_TICK_MS = 30_000;

const hidden = () => typeof document !== "undefined" && document.visibilityState === "hidden";
const malformed = () => Object.assign(new Error(""), { malformed: true });

export function usePharmacy(store, { everyMs = PHARMACY_TICK_MS } = {}) {
  const [state, setState] = useState({ data: null, error: null });
  const alive = useRef(true);
  //: the sequence of the latest read issued; an answer to an earlier one is dropped, so the screen never shows
  //: an older list over a newer one (useTasks)
  const seq = useRef(0);
  const read = useCallback(async () => {
    const mine = ++seq.current;
    try {
      const data = await store.track(() => store.api.pharmacy());
      if (!data || !Array.isArray(data.rows)) throw malformed();
      if (alive.current && mine === seq.current) setState({ data, error: null });
    } catch (error) {
      if (alive.current && mine === seq.current) setState((s) => ({ data: s.data, error }));
    }
  }, [store]);
  useEffect(() => {
    alive.current = true;
    read();
    const id = setInterval(read, everyMs);
    const wake = () => { if (!hidden()) read(); };
    document.addEventListener("visibilitychange", wake);
    return () => {
      alive.current = false;
      clearInterval(id);
      document.removeEventListener("visibilitychange", wake);
    };
  }, [read, everyMs]);
  return { data: state.data, error: state.error, refresh: read };
}
```

```jsx
/** A count as the server sent it, or a dash for one that is no whole number — never a 0 the server did not send. */
const countText = (value) => (Number.isInteger(value) ? String(value) : "—");

function Counters({ counts, asOf }) {
  const { t } = useI18n();
  return (
    <div data-counters>
      <div className="grid grid-cols-2 gap-2 min-[640px]:grid-cols-4">
        {TILES.map((tile) => (
          <div key={tile.field} className="rounded-box border border-line bg-card px-3 py-2">
            <b data-testid={`count-${tile.field}`} className={`block font-data text-23 ${counts?.[tile.field] > 0 ? tile.tone : "text-ink"}`}>
              {countText(counts?.[tile.field])}
            </b>
            <span className="block text-12 text-mute">{t(tile.label)}</span>
            {tile.second ? (
              <span data-testid={`count-${tile.second}`} className="block text-12 text-mute">
                {t("eczane.count.noRecord", { n: countText(counts?.[tile.second]) })}
              </span>
            ) : null}
          </div>
        ))}
      </div>
      {asOf ? <p data-as-of className="m-0 mt-1 text-12 text-mute">{asOf}</p> : null}
    </div>
  );
}

function Row({ row, nowMs, fresh, canOpen }) {
  const { t, lang } = useI18n();
  const stamp = (ms) => (ms === null ? "—" : dayStamp(ms, nowMs));
  const bed = bedNameOf({ bedLabel: row.bed_label, patient_id: row.patient_id });
  const who = (
    <>
      <span className="block font-data text-13.5 font-bold text-ink">{bed}</span>
      <span className="block text-12.5 font-normal text-mute">{nameOf(row, t)}</span>
    </>
  );
  const antibiotic = antibioticCell(row, nowMs, fresh);
  const state = t(antibiotic.key, {
    duration: antibiotic.duration ? t(antibiotic.duration.key, antibiotic.duration.params) : "—",
    time: stamp(antibiotic.timeMs),
    state: String(antibiotic.state ?? "—"),
  });
  const pressors = pressorLines(row, nowMs, fresh);
  const creatinine = creatinineCell(row);
  const fluid = fluidCell(row);
  return (
    <tr data-patient={row.patient_id} data-state={String(antibiotic.state ?? "")}>
      <th scope="row" className="!normal-case !tracking-normal">
        {canOpen
          ? <a href={`#/patients/${encodeURIComponent(row.patient_id ?? "")}`} className={`block rounded-md ${FOCUS_RING}`}>{who}</a>
          : who}
      </th>
      <td data-cell="pressors">
        {pressors.length === 0 ? <span className="text-mute">{t("eczane.noRecord")}</span> : pressors.map((line) => (
          <span key={line.drug} className="block">
            {t(line.key, {
              drug: line.drugKey ? t(line.drugKey) : line.drug,
              rate: line.rate,
              time: line.aged ? (ageText(t, line.at, nowMs) ?? "—") : stamp(line.atMs),
            })}
          </span>
        ))}
      </td>
      <td data-cell="antibiotic">
        {antibiotic.tone
          ? <StatusPill tone={antibiotic.tone}>{state}</StatusPill>
          : <span className={antibiotic.state === "none" ? "text-mute" : ""}>{state}</span>}
        {antibiotic.second ? (
          <span className="mt-0.5 block text-12 text-mute">{t(antibiotic.second.key, { time: stamp(antibiotic.second.timeMs) })}</span>
        ) : null}
      </td>
      <td data-cell="creatinine" className="font-data">
        {creatinine
          ? t("eczane.creatinine", { value: creatinine.value, time: stamp(creatinine.atMs) })
          : <span className="font-text text-mute">{t("eczane.noRecord")}</span>}
      </td>
      <td data-cell="fluid">
        {fluid ? (
          <>
            <span className="block font-data font-bold">{t("eczane.fluid.balance", { value: signedMlText(lang, fluid.balance) })}</span>
            <span className="block text-12 text-mute">
              {t("eczane.fluid.detail", { intake: mlText(lang, fluid.intake), output: mlText(lang, fluid.output), time: stamp(fluid.lastMs) })}
            </span>
          </>
        ) : <span className="text-mute">{t("eczane.fluid.none")}</span>}
      </td>
    </tr>
  );
}

export function EczaneScreen() {
  const { t } = useI18n();
  const { user, store } = useSession();
  const nowMs = useBoardNow(10_000);
  const { data, error } = usePharmacy(store);

  const rows = data?.rows ?? [];

  const answered = answeredAt === null ? "—" : dayStamp(answeredAt, nowMs);
  const reason = error ? (error.malformed ? t("eczane.malformed") : readErrorText(t, error)) : null;
  const standard = data?.antibiotic_window_min === WINDOW_MIN && data?.antibiotic_window_source === WINDOW_SOURCE;

      {!data && !error ? <Note tone="info" icon="clock">{t("eczane.loading")}</Note> : null}

        </Alert>

      {data && (fresh || rows.length > 0) ? <ScopeNote scope={data.scope} scopeNote={data.scope_note} /> : null}
      {data ? <Counters counts={data.counts} asOf={fresh ? null : t("eczane.asOf", { time: answered })} /> : null}
      <Note tone="info" icon="pill">{t("eczane.note")}</Note>
      {data?.fluid_truncated ? <Note tone="warn" icon="alert">{t("eczane.truncated")}</Note> : null}

              <th>{t("eczane.col.patient")}</th>
              <th>{t("eczane.col.pressors")}</th>
              <th>{t("eczane.col.antibiotic")}</th>

            : t("eczane.sourceOther", { minutes: countText(data.antibiotic_window_min), source: String(data.antibiotic_window_source ?? "—") })}
        </p>
      ) : null}
      <p data-footer className="m-0 text-12.5 text-mute">{t("eczane.footer")}</p>
    </div>
  );
}
```
